## 📌 About This Repository

This repository contains my Linux and Operating Systems lab practicals. It includes Bash scripts, C programs, and command-line exercises covering different concepts of Linux and operating system fundamentals.

The practicals focus on learning how to work with the Linux terminal, automate tasks using shell scripts, manipulate files, manage processes, and understand memory and CPU behaviour.

## 🚀 Getting Started

Clone this repository:

```bash
git clone https://github.com/RedMoon-002/Linux-Commands.git
```

Navigate to the project:

```bash
cd Linux-Commands
```

Open an experiment folder:

```bash
cd exp3a
```

Run a Bash script:

```bash
bash exp3a.sh filename
```

Compile and execute a C program:

```bash
gcc exp9.c -o exp9
./exp9
```

For scripts that need executable permission:

```bash
chmod +x filename.sh
./filename.sh
```
