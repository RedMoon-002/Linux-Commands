# Linux Basic Commands

This repository contains some basic Linux commands and their one-line explanations. These commands are useful for beginners learning Linux and working with the terminal.

## 1. Basic Navigation Commands

| Command | Explanation |
|---|---|
| `pwd` | Displays the current working directory. |
| `ls` | Lists files and directories. |
| `ls -l` | Displays files in detailed list format. |
| `ls -a` | Shows all files, including hidden files. |
| `cd` | Changes the current directory. |
| `cd ..` | Moves one directory backward. |
| `clear` | Clears the terminal screen. |

## 2. File and Directory Commands

| Command | Explanation |
|---|---|
| `touch file.txt` | Creates an empty file. |
| `mkdir folder` | Creates a new directory. |
| `rmdir folder` | Removes an empty directory. |
| `rm file.txt` | Deletes a file. |
| `rm -r folder` | Deletes a directory and its contents. |
| `cp file1 file2` | Copies a file. |
| `mv file1 file2` | Moves or renames a file. |

## 3. File Reading Commands

| Command | Explanation |
|---|---|
| `cat file.txt` | Displays the contents of a file. |
| `less file.txt` | Views file contents page by page. |
| `head file.txt` | Displays the first 10 lines of a file. |
| `tail file.txt` | Displays the last 10 lines of a file. |
| `nano file.txt` | Opens a file in the Nano text editor. |
| `wc file.txt` | Counts lines, words and characters. |

## 4. System Information Commands

| Command | Explanation |
|---|---|
| `date` | Displays the current date and time. |
| `cal` | Displays the calendar. |
| `whoami` | Displays the current username. |
| `who` | Shows currently logged-in users. |
| `uname -a` | Displays detailed system information. |
| `hostname` | Displays the system's hostname. |
| `uptime` | Shows how long the system has been running. |

## 5. Process Management Commands

| Command | Explanation |
|---|---|
| `ps` | Displays currently running processes. |
| `ps aux` | Displays detailed information about running processes. |
| `top` | Displays real-time system processes and resource usage. |
| `kill PID` | Terminates a process using its process ID. |
| `sleep 5` | Pauses execution for 5 seconds. |
| `getpid()` | Returns the process ID in a C program. |
| `fork()` | Creates a new child process in a C program. |
| `wait()` | Makes a parent process wait for a child process. |

## 6. Permission Commands

| Command | Explanation |
|---|---|
| `chmod` | Changes file or directory permissions. |
| `chown` | Changes file ownership. |
| `chgrp` | Changes the group ownership of a file. |
| `sudo` | Executes a command with administrator privileges. |

## 7. Networking Commands

| Command | Explanation |
|---|---|
| `ip addr` | Displays network interface information. |
| `ping google.com` | Checks connectivity to a network host. |
| `hostname -I` | Displays the system's IP address. |
| `curl` | Transfers data from or to a server. |
| `wget` | Downloads files from the internet. |

## 8. Other Useful Commands

| Command | Explanation |
|---|---|
| `echo` | Displays text in the terminal. |
| `man` | Opens the manual page of a command. |
| `history` | Displays previously executed commands. |
| `find` | Searches for files and directories. |
| `grep` | Searches for specific text in files. |
| `df -h` | Displays available disk space. |
| `free -h` | Displays memory usage. |
| `exit` | Closes the current terminal session. |

---

## Conclusion

These are some commonly used Linux commands that help users navigate directories, manage files, monitor processes, and understand system operations. Learning these commands provides a strong foundation for working with Linux.
